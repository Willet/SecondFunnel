# Creating a SecondFunnel Theme: Intro

SecondFunnel campaigns are beautiful image palettes that try to get the user to
interact.

This tutorial will give you an overview of SecondFunnel pages and show you how
you can create a theme for your page.

## You will need

To create a new theme, you will need

- a web browser
- a text editor
- basic knowledge of **HTML**, **CSS**, and **JavaScript**
- [our example](example.html)
- this tutorial
- [the style document](style.md)

## Step One: make a functioning page

Use [this example](example.html) as the basis for your page. Modify it according
to this tutorial and [the style tutorial](style.md) to achieve the appearance
you want.
In order for SecondFunnel to function, your page has to include:

- at least minimal templates (included in the example)
- the element `<div id="discovery-area></div>` (included in the example)
- the stylesheets included in the example.
- the scripts included in the example.

At every step, ensure your page satisfies all the requirements.

## Step Two: modify the look of your page

Move elements around, and add styles according to [the style tutorial](style.md).
Make sure you store your styles in a styles.css file and include it in a css/
folder.

## Step Three: modify templates if you need to.

To make it easier to theme a landing page, its parts are broken down into
several Underscore templates. If you need to modify a template, please refer to
[the templates  documentation](templates.md)

## Step Three: add widgets and scripts to your page

SecondFunnel has built-in support for the following widgets:

- gallery
- tabs
- accordions

You can find demos and tutorials related to those widgets in
[the widgets tutorial](widgets.md)

If you would like to add external scripts, include them in a js/ folder, and
upload them to SecondFunnel along with the rest of your theme.
